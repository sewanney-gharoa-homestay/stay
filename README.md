# 🏔️ Sewanney Gharoa Homestay | Sittong

Official website for **Sewanney Gharoa Homestay**, nestled in the scenic hills of **Ghalaytor Bazar, Sittong Khasmahal, West Bengal**. Designed to offer guests a tranquil mountain retreat with panoramic views of Mt. Kanchenjunga, lush terraced valley landscapes, authentic regional cuisine, and warm Himalayan hospitality.

---

## 🌟 Key Features

### 1. Hero & Direct Booking Actions
- Full-bleed hero banner with elegant typography and gold accents.
- Instant contact shortcuts:
  - 📞 **Direct Call**: One-tap phone connection (`+91 7044239256`).
  - 💬 **WhatsApp**: Direct chat link for instant inquiries and reservations.
  - 🌐 **Facebook**: Quick link to the official Facebook page.

### 2. About the Homestay
- An engaging introduction to the homestay experience—*gharoa* (home-like) comfort, morning sunrises over Kanchenjunga, and serene tea-sipping valley vistas.

### 3. Amenities & Experiences ("What We Offer")
- **Clean 2-Column Grid**: Highlights 4 key amenities by default for a clutter-free view.
- **Interactive Expansion**: Click **"+ Show More Amenities"** to reveal 10 additional customized amenities (cozy fireplace, nature walks, bicycle rentals, library, hot showers, and more).
- Automatically responsive to a single column on mobile devices.

### 4. Places to Visit Near Stay
- Highlights top local tourist attractions around Ghalaytor Bazar & Sittong:
  - 🌄 **Ahaldara Viewpoint**: 360-degree views of hills, tea gardens, and Kanchenjunga.
  - 🏞️ **Namthing Pokhri (Lake)**: Pine forest lake habitat for the rare Himalayan Salamander.
  - 🌉 **Jogighat Bridge & Riyang River**: Suspension bridge with fluttering prayer flags over mountain streams.
  - 🍊 **Local Orange Orchards**: Winter orange blossom and harvest walks.
  - 🏯 **Sittong Monastery**: Historic Buddhist monastery with peaceful spiritual ambiance.
  - 💧 **Jogikhola Waterfall & Rock Climbing**: Natural rock bed and roadside waterfall.
- Quick link to explore more nearby attractions on Google.

### 5. Interactive Photo Carousel ("Images from the Stay")
- Automatic 8-second slideshow showcasing 23 authentic local homestay photos.
- Smooth manual navigation with Previous (`❮`) and Next (`❯`) controls.

### 5. Full Image Gallery & Lightbox Player
- **Modal Popup**: Browse all 23 high-resolution photos in a responsive grid (4 columns on desktop, 1 column on mobile).
- **Sticky Header**: Pinned header bar with close (`✕`) button and title that stays visible at all times while scrolling.
- **Full-Screen Lightbox**:
  - Click any image to view it full size.
  - On-screen Previous (`❮`) and Next (`❯`) navigation arrows.
  - Photo counter display (e.g., `5 / 23`).
  - **Keyboard Navigation**: Use **Left Arrow (`←`)**, **Right Arrow (`→`)**, and **Escape (`Esc`)** keys.

### 6. Video Gallery & Lightbox
- High-definition local promotional videos (`.mp4`) hosted directly within the project.
- Native HTML5 preview thumbnails with animated play icons.
- Lightbox video player that fits comfortably inside the viewport with zero window scrolling.
- Automatic playback pause when the modal is closed.

## 🚀 How to Run Locally

Because this is a pure static website with no compilation steps required:

1. **Direct Browser**:
   - Double-click `index.html` or open it in any modern web browser (Chrome, Edge, Firefox, Safari).

2. **Local HTTP Server** *(Recommended for video playback and assets)*:
   - Using Python:
     ```bash
     python -m http.server 8000
     ```
   - Using Node.js / npx:
     ```bash
     npx serve .
     ```
   - Open [http://localhost:8000](http://localhost:8000) in your browser.
